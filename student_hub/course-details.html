Web Development Fundamentals

Course Code: CE401  |  Credits: 4  |  Instructor: Prof. Sharma

Course Overview

This course introduces students to fundamental web development concepts including HTML5, CSS3, and basic JavaScript. Students will build static and dynamic web pages and learn best practices for accessible, semantic web design.

Syllabus / Topics Covered

  1. Introduction to the Web and HTML5
  2. Semantic Markup and Accessibility
  3. CSS3 — Selectors, Box Model, Flexbox
  4. Responsive Design and Media Queries
  5. JavaScript Basics and DOM Manipulation
  6. Forms, Validation, and Events
  7. Introduction to Backend Concepts
